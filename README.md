# Hospital-data-project-SQL
This project focuses on analyzing hospital data using SQL to extract meaningful insights related to patients, doctors, departments, hospital stays, and medical expenses.
The objective of this project was to practice SQL querying and transform hospital data into useful business and operational insights. I worked with hospital-level data to answer real-world analytical questions and identify important patterns.

Key Analysis Performed
Calculated the total number of patients across hospitals.
Analyzed the average number of doctors available at each hospital.
Identified the top 3 departments with the highest patient count.
Determined hospitals with the highest medical expenses.
Calculated average daily medical expenses for hospitals.
Analyzed patient length of stay using admission and discharge dates.
Calculated the total number of patients treated by city.
Compared the average length of stay across departments.
Identified the department with the lowest number of patients.
Generated a monthly medical expenses report using admission dates.

Project Outcome

This project strengthened my ability to use SQL for data analysis and business problem-solving, particularly in aggregating data, analyzing trends, comparing departments, and generating actionable insights from structured healthcare data.
